# AGENTS.md — AI Agent Guidance & Architectural Reference

This document serves as the primary technical specification and operational playbook for autonomous AI coding agents working on the `kreier/T18` repository.

---

## 1. System Overview & Architecture

`kreier/T18` is an edge-native, zero-trust telemetry fleet monitoring system tailored for the **LILYGO TTGO T18** (and fully compatible with **LILYGO T8**):

- **Edge Nodes (Firmware)**: ESP32 microcontrollers operating unattended on 18650 battery or USB. Every 10 minutes, nodes wake from light sleep, run 2.4 GHz scans, promiscuous channel contention surveys, network latency probes, and IO35 battery sensing, uploading telemetry before returning to light sleep.
- **Edge Backend (Worker & D1)**: Cloudflare Worker written in TypeScript deployed at `https://t18.kreier.workers.dev` backed by Cloudflare D1 (`t18-mon-db`). Handles device registration, bearer token validation, telemetry batch ingestion, two-tier caching, automated 30-day data retention, and zero-redirect OTA streaming proxies.
- **Dual Dashboards (Web)**: Server-rendered dashboard on Cloudflare Worker (`https://t18.kreier.workers.dev`) and static mirror on GitHub Pages (`https://kreier.github.io/T18`) driven by a single-source frontend engine in `worker/src/frontend.ts`.

## 2. Hardware Profiles & ADC Battery Sensing

| Board Target | Status LED Pin | ADC Battery Pin | Divider Ratio | Notes |
| ------------ | -------------- | --------------- | ------------- | ----- |
| **BOARD_T18** (LILYGO T18) | GPIO 5 | GPIO 35 | 0.50f (100k/100k) | Standard LiPo 18650 single-cell |
| **BOARD_T8** (LILYGO T8) | GPIO 21 | GPIO 35 | 0.50f (100k/100k) | Standard LiPo single-cell |
| **BOARD_DEVKIT** (DevKit V1) | GPIO 2 | -1 (Disabled) | 0.50f | AC / USB powered |
| **BOARD_CUSTOM** | User-defined | User-defined | User-defined | Custom GPIOs |

### Battery Voltage Calculations
- ADC voltage is read using `analogReadMilliVolts(pin)` across 5 averaged samples and divided by `hw.battery_divider`.
- Standard single-cell LiPo curve spans 3.30 V (0%) to 4.20 V (100%).
- Formatted strings required by UI:
  - `"Running on battery for XXXh (DD days X hours)"`
  - `"Estimated runtime YYYh (DD days Y hours)"`

## 3. Key Invariants & Non-Negotiable Rules

1. **Dual Build Firmware Parity**: Embedded logic resides in `firmware/include/*.h`. `firmware/src/main.cpp` and `firmware/T18/T18.ino` are minimal wrappers.
2. **Flash Wear & Memory Safety**: In-memory first telemetry transmission; raw flash circular buffer (`raw_spool`) used only when offline.
3. **Zero-Redirect OTA Streaming**: Direct binary streaming proxy via `/api/ota/download/:filename`.
4. **Single-Source Frontend**: Generated by `renderDashboardHtml()` in `worker/src/frontend.ts`. Run `npm run build:docs` after editing.
